Connect Genius song info

Stop any previous server with Ctrl+C, then start the app server with py server.py from the Spotify Viewer folder. Open http://127.0.0.1:8000/. This server routes Genius API requests through your computer to avoid browser CORS blocks. Open genius.com/api-clients, create or open an API client, and copy its Client Access Token. Paste that value below—not the Client ID, Client Secret, or Spotify token. The token is saved in this browser and sent to the local app server, which forwards it to Genius.

If Genius returns 403: Action forbidden for current scope, it is refusing that API client's access. Confirm you copied its Client Access Token; if you did, there is no extra Spotify setting to add, and Genius may not authorize that client.

Connect your Spotify

Serve this page at 127.0.0.1:8000 (Spotify does not allow localhost redirect URLs). Create a Spotify app in the Developer Dashboard, paste its Client ID, and add the exact redirect URL below. Song history needs additional Spotify permissions; reconnect and approve them to see play, liked-song, and playlist dates. Your credentials stay in this browser.
